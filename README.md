# Ronin Skill Library

Ronin's reusable build skills are free to browse and download. No Scripture Armor subscription or checkout is required. This repository is a skill collection, not an installer, a hosted CRM, or a service that runs the skills for you.

## What's in this repository

- `<name>/SKILL.md`: skill instructions and, in some directories, supporting references, templates, or helpers.
- [CRM_COMPOSITION_INDEX.md](CRM_COMPOSITION_INDEX.md): composition guides for assembling skills into larger projects.
- [skill-catalog.json](skill-catalog.json): the generated catalog for discovery. The tracked skill files are the source of truth when the catalog and tree differ.
- [skill-harvest/](skill-harvest/): the catalog-building workflow and its generator.

## Fleet Learning and reuse

Fleet Learning is a separate runtime, not part of this repository. Its library feed is intended to use reviewed, versioned public skills. A file being present in the repository does not by itself mean it has passed that review or is available through Fleet Learning.

Free access is not a blanket software license. Follow any license and attribution terms that accompany a skill or its dependencies. Do not add credentials, customer data, private workspaces, or fleet records to this repository.

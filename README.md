# Ronin Skill Library

Reusable, sellable build skills. Each directory is one skill (`<name>/SKILL.md`), auto-discovered by Claude Code and composable into any client build.

- **[CRM_COMPOSITION_INDEX.md](CRM_COMPOSITION_INDEX.md)** — the pick-and-ship map: recipes (local-business CRM · lead-gen engine · agency · investor portal · dropship · team portal) + add-on packs over the whole library.
- **`skill-harvest`** — the repeatable strip→diff→author→verify pipeline that grows this library from any build. Run it as the closing step of a build (or across the portfolio) and it folds net-new capabilities in automatically.

Patterns and techniques only — no client data. Private; do not publish.

# Reconfiguring the Engine for Other Verticals

The default target is an independent restaurant — the Owner.com outcome, for
orosolu.org. The same two-mode pipeline (prospect-scan and targeted, both ending in
a deep dive → Build Brief → `website-build-standard`) works for any local business a
site gets built for. Only the buy-box and the field/media checklists change; the
workflow, the deep-dive rule, the discipline, and the handoff stay identical.

## What to change per vertical

1. **Buy-box** (`buy-box.md`) — copy it, set a new name+version (e.g.
   `contractor-remodel v1`), rewrite the ICP, disqualifiers, the six scoring
   dimensions + their 0–5 anchors, and the weights. Keep ~5 core + 1 fit modifier so
   the completeness gate stays meaningful. This is what qualifies/ranks shops in a
   prospecting scan and tiers a targeted shop.
2. **Field checklist** (`intel-checklist.md`) — swap the facts the Build Brief needs.
   Contractors: services, service area, licensing, quote/booking. Clinics:
   specialties, insurance accepted, online booking. Retail: product lines, hours.
3. **Best sources** — retail/services lean on GBP, the own site, and category
   directories more than delivery apps. Clinics add Healthgrades/Zocdoc; contractors
   add Angi/BBB/state licensing.
4. **Media emphasis** (`media-harvest.md`) — restaurants → food + interior + hero
   reel; contractors → before/after project photos + crew; retail → product shots +
   storefront; clinics → facility + team headshots. Hero-candidate video and palette
   sampling apply to all.
5. **Section list** in the Build Brief — menu/reservations vs services/quote vs
   booking/insurance.

## What never changes

- **Build on `business-profile-recon`** for the verified fact sweep — don't duplicate.
- **Deep-dive every qualified/targeted shop; DROP shops get no dive.**
- **Deterministic scoring; evidence before conclusions; Unknown is valid.**
- **Catalog media, don't blind-download; rights-flag every asset.** Higher-sensitivity
  verticals (clinics) get *more* cautious with imagery and never touch private or
  patient data.
- **Public data only**, respect fetch boundaries, corroborate customer-facing facts,
  approval before outreach/writes.
- **Outputs are always a Lead Sheet (prospecting) and/or Build Brief + Media Manifest**
  shaped for `website-build-standard`, versioned by buy-box. That handoff is the constant.
